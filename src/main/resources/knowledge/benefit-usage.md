# 权益卡使用规则

## 券的类型
平台权益卡分为两类：到店核销券（type=0）与限时秒杀券（type=1）。到店核销券在商户详情页直接购买，不限线上库存；限时秒杀券有固定库存与购买时间窗，抢完即止。

## 查看与核销
已购权益卡在「我的」页查看，列表展示券名、订单号与状态。到店后向店员出示券码，由门店在后台核销，核销后订单状态变为「已核销」，该券不可再次使用。

## 有效期
每张券的面板标注有效期起止时间，超出有效期后不可核销。秒杀券的有效期即其时间窗，过期未使用的券按退款规则处理。

## 叠加与兑现
单笔消费能否叠加多张券、是否可与其他优惠同享，由商户在券的「使用规则」中标注，请以券详情页展示的规则为准。权益卡不可兑换现金，不设找零。

## 退款
退款规则见《退款与取消规则》，已核销的券不支持退款。
